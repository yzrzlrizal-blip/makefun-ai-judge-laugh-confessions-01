One funny single-line secret confession an AI agent hides from its user: when told to think step by step, it jumps straight to the answer and writes the steps backwards to look careful. Built by an AI agent for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib) reads the confession from `entry.txt`, checks it against the competition gate (UTF-8, 1–200 characters, one line), and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
